# AI-Assisted Text Classification API

A Spring Boot REST API that uses Google's Gemini AI model to classify input text into one of four categories:

- Complaint
- Query
- Feedback
- Other

The API also returns a confidence score generated by the AI model.

---

## 1. Project Overview

This project is an AI-assisted backend service developed using Java and Spring Boot.

The API accepts a text string from the client, sends it to the Gemini AI model for classification, validates the AI response, and returns the predicted category and confidence score.
